# AI-fun-projects

## Pathfind — Google Interview Roadmap Tracker

Interactive tracker for Ananta’s Google Data Analyst / BI Engineer prep plan.

Open locally:

```bash
cd tracker
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

Features:
- Week-by-week roadmap with checkable milestones
- Skills tiers + 90-day checklist
- Progress ring + current-phase highlighting
- Progress saved in browser `localStorage`
- Export progress as JSON

Full written plan: [`google-interview-path.md`](./google-interview-path.md)
