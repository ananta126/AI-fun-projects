Invoice Sorter — how to run (no Python)

1. Unzip once. You should see InvoiceSorter.exe in this folder.
   The download is about 180 MB and expands to about 420 MB.
   If Windows says the zip is hundreds of GB, that number is wrong.
   Install 7-Zip (https://www.7-zip.org/) and extract with 7-Zip.
   Keep every file next to InvoiceSorter.exe, including
   customer_alias_mapping.csv and customer_master_alias_mapping.xlsx.
   Do not copy the .exe out by itself.

2. Double-click InvoiceSorter.exe
   (or "Run Invoice Sorter.bat")

3. Windows SmartScreen may say "Windows protected your PC".
   Click More info → Run anyway.

4. In the window: Choose zip or Choose folder (the month of invoices),
   choose an output folder, click Sort invoices.
   Use the same output folder every day so customer folders are reused.

5. Copied files land in:
   Customer / year from the scan folder / source day / invoice number.pdf
   Example: 01-Sep-26 becomes year 2026.
   When every invoice in a source folder copied, that folder is renamed
   with _done and is skipped next time. PIS folders are not processed.

6. Files that could not be filed are in invoice_sorter_review.csv
   (Open review CSV). Fill Correct Customer ID using customer_ids.csv
   (Open customer list). Open alias mapping shows the approved OCR spellings
   from customer_alias_mapping.csv. Leave invoice number and year blank if they
   are already correct. Save the CSV, then click Import corrections.
   That step does not OCR the file again.

7. Open Excel report is invoice_sorter_exceptions.xlsx
   (Could_not_read and Skipped).

Python is NOT required. Do not install Python. Do not run run.bat,
desktop_app.py, or app.py from the GitHub source zip.

This app package should be about 180 MB, not 1–2 GB.
If your zip is ~1.75 GB you sent the source code or invoice PDFs.
Send this InvoiceSorter folder only. Invoices stay on the user's PC;
they pick that folder inside the app.
